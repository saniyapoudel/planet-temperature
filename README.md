

I have completed a Planet Temperature Prediction** project using a planetary dataset. The main objective of my project was to predict planetary temperature using relevant planetary and stellar features.

1. Data Loading: I loaded the dataset and examined its structure, source, features, records, and target variable.

2. Data Inspection & EDA: I inspected the dataset and performed exploratory data analysis to understand the data distribution, feature characteristics, missing values, and relationships between the features and planetary temperature.

3. Data Cleaning: I checked and handled missing values, duplicate records, inconsistent values, and unsuitable data. I cleaned the dataset so that it could be used properly for machine-learning model training.

4. Feature Engineering: I selected and prepared useful features that can contribute to predicting planetary temperature and removed unnecessary features where required.

5. Vectorization:I converted non-numerical or categorical information into numerical form wherever required so that the machine-learning models could process the data.

6. Scaling: I scaled the numerical features using an appropriate scaling technique so that features with different numerical ranges could be handled consistently by the models.

7. Model Training:I divided the prepared data into training and testing sets and trained suitable regression models to learn the relationship between the input features and planetary temperature.

8. Validation & Testing:I tested the trained models using suitable regression evaluation metrics such as MAE, MSE, RMSE, and R² to measure prediction performance.

9. Experimentation & Comparison: I experimented with different regression models and compared their performance using the evaluation results. I selected the final model based on the actual results obtained from the experiments.

10. Model Saving: I saved the final trained model and the required preprocessing components so that the model could be reused for future predictions without retraining.

11. Working Prototype: I created a working prediction prototype using the saved model. The prototype accepts the required planetary features and produces a predicted planetary temperature.

Overall, I completed the required machine-learning workflow from **data loading and EDA to cleaning, feature engineering, vectorization, scaling, model training, testing, model comparison, model saving, and a working prototype**.
